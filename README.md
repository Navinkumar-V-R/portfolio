# Navinkumar V R — Portfolio

A responsive portfolio built with React and Vite. It presents selected web and automation projects, experience, skills, certifications, and contact links.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

## Structure

- `src/components/` contains the page sections and reusable UI components.
- `src/data/portfolio.js` contains project, skill, and certification content.
- `public/Navinkumar_Resume.pdf` is the downloadable résumé.
